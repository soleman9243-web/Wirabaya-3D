Essential UI Sound Effects (Free)
=================================

150 clean, neutral interface sounds for any game or app: 30 UI events with
5 genuinely different versions of each. Free for personal and commercial
projects.

EVENTS
  click, hover, keypress, select, confirm, cancel, error, alert, notify,
  toggle on, toggle off, open, close, transition, reward, unlock, scan, pop,
  swipe, tick, drop, dialogue, coin, purchase, equip, page, save, charge,
  level up and deny

FOLDERS
  Audio/          <event>_NN.wav (5 versions per event)
  Scripts/        RandomSfx.cs
  manifest.json   every event and the path of each version

HOW TO USE
  Scripts/RandomSfx.cs: add it to a GameObject (it adds an AudioSource),
  drag the 5 versions of one sound into Variations and call Play() from a
  button. It plays them from a shuffled bag, so the same clip never plays
  twice in a row and nothing repeats until every version has been heard.
  Keep the file named RandomSfx.cs.

FORMAT
  Mono WAV, 44.1 kHz, 16-bit. Every version is a separate sound, not one
  file pitch-shifted. Peaks under -1 dBFS.
